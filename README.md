# انشانویس ✍️

یک ابزار ساده برای ساخت انشای فارسی با کمک هوش مصنوعی.

کاربر موضوع، پایه تحصیلی، طول، نوع انشا و جنسیت را انتخاب می‌کند و یک انشای متناسب با سطح دانش‌آموز دریافت می‌کند.

## Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* Groq API

## اجرا

```bash
npm install
npm run dev
```

برای استفاده از Groq، متغیر زیر را در `.env.local` قرار دهید:

```env
GROQ_API_KEY=your_groq_api_key
```
